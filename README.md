# ai-settlement

Verified-delivery escrow for AI agent jobs on the XRP Ledger (testnet only).

| Folder | What's in it |
|---|---|
| `QUICKSTART.md` | Start here: a first verified-delivery escrow on testnet in about 15 minutes |
| `edr/` | Engineering decision records. EDR-011 governs Phase 1, EDR-012 Phase 2 and EDR-013 Phase 3. |
| `research/` | The market writeup behind the project |
| `xrpl-escrow/` | The code. Start with `xrpl-escrow/README.md`. Rules: `CLAUDE.md` (Phase 1), `CLAUDE_PHASE2.md` |
| `xrpl-escrow-py/` | The Python client SDK (Phase 3). Start with `xrpl-escrow-py/README.md` |
| `docs/` | `THREAT_MODEL.md` (what the kit does not protect against) and `trial/` (the developer trial kit) |
| `CHANGELOG.md`, `CONTRIBUTING.md`, `SECURITY.md` | Release notes, how to contribute, how to report a security problem |
| `xrpl-escrow/docs/reviews/` | Review brief (`REVIEW.md`), Phase 2 diff, and the reviewer's verdict (`VERDICT.md`). Reviewer: Gpno |

Put your `Agents.md` at this level, so `edr/`, `Agents.md` and `xrpl-escrow/` sit side by side as the Phase 2 docs expect.
