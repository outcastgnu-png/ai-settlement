   (node-gyp rebuild) and esbuild (postinstall). Both still loaded and worked (checked with a
   :memory: SQLite query and an esbuild transform). npm 11 also added `"hasInstallScript": true`
   for better-sqlite3 to package-lock.json; that one-line change was reverted, not kept.
2. The README's Windows quickstart says to open PowerShell in the `escrow-demo` folder, and the
   Phase 1 section says `cd escrow-demo`. The folder in this repo is `xrpl-escrow`.
3. Reputation counts each job by its current status, so a job that went expired_unclaimed and
   was then refunded counts as refunded, with expiredUnclaimed staying 0 (see section B).
4. The reconnect check runs the repo's LedgerWatcher class in-process (runs/2026-10-21-windows/
   reconnect.mts), not the `npm run watcher` process, because the socket has to be cut from
   inside. The drop is ws.terminate(): an abrupt close 1006 with no close handshake, after which
   xrpl.js reconnects on its own. The npm-started watcher was stopped first.
5. Sections A and B used runs/2026-10-21-windows/quickstart.mts against services started with
   `npm run registry`, `npm run oracle`, `npm run watcher` (each its own process), run as
   `npx tsx <script> quickstart|expired` from xrpl-escrow\.
